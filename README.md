# 📊 Sales Data Analysis (EDA)

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on a sales dataset to uncover meaningful insights, patterns, and trends.

## 🎯 Objectives
- Understand the dataset structure
- Analyze sales performance across regions, categories, and segments
- Identify top-performing cities
- Extract actionable insights from data

## 📁 Dataset
The dataset contains:
- Order details
- Customer information
- Product categories
- Sales data

## ❓ Key Questions
- Which region has the highest sales?
- Which category performs best?
- Which segment contributes most?
- Which cities generate the highest revenue?

## 📊 Analysis Performed
- Data exploration using Pandas
- Data visualization using Seaborn and Matplotlib
- Trend and pattern identification

## 📈 Key Insights
- South and East regions show higher sales
- Home Office segment contributes more compared to others
- New York is the top-performing city

## ⚠️ Data Limitations
- No profit column available
- Limited dataset features

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🚀 Conclusion
This project demonstrates the ability to analyze data, create visualizations, and extract meaningful insights that can support decision-making.
